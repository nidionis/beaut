beaut - minimal hub/worker Docker fabric

usage: beaut <command>

  hub serve                  run the hub main listener
  worker serve               run the worker loop and snapshot receiver
  run PROJECT_FOLDER         pack a Dockerfile/compose project as a job
  jobs                       print job state as JSON
  status [--json]            show the hub inventory
  resources [--raw|--json]   show local resources
  doctor                     check config and dependencies
  deploy hub|worker          install over SSH using conf/conf.env
  first-conn ROLE TARGET SUDO_USER [PASSWORD]
                             create accounts, keys and directories on a new node

configuration: conf/conf.env, then conf/node.env
runtime entrypoints: bin/beaut-hub, bin/beaut-work, bin/beaut-worker
