beaut

Minimalist shared-computing platform: a control server that serves scripts and validates tokens, plus nodes that fetch them.

Site

  • /hello — example page, also a runnable script (curl -fsS http://{{SERVER_HOST}}:{{HTTP_PORT}}/hello | sh)

The journal and personal tree are served only under the secret path.

Builtins

These live inside this site tree, under site/:

  • /node — node bootstrap script (curl -fsS http://{{SERVER_HOST}}:{{HTTP_PORT}}/node | sh)
  • /scripts/ — server scripts and libraries
  • /deploy/ — deployment files
