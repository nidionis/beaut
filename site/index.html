beaut

Minimalist shared-computing platform: a control server that serves scripts and validates tokens, plus nodes that fetch them.

Entry points

  • /node — node bootstrap script (curl -fsS http://192.168.8.240:8080/node | sh)
  • /hello — example directory default script (curl -fsS http://192.168.8.240:8080/hello | sh)

The personal journal lives under a secret prefix: /<hidden>/diary/YYYY-MM-DD.md.
